# cfk44.github.io

Personal website of Christoph Friedrich Koch (CFK) — Business Development × Data Science, Berlin.

**Live:** [https://cfk44.github.io](https://cfk44.github.io)

## Stack
Static HTML/CSS/JS in a single file — no build process, no dependencies.
Typography: Space Grotesk + JetBrains Mono (Google Fonts).

## Structure
   File          | Purpose                          |
 |---------------|----------------------------------|
 | `index.html`  | Entire site (bilingual DE/EN, toggle top-right) |
 | `404.html`    | Error page                       |
 | `favicon.svg` | Site icon (elevation profile mark) |
 | `robots.txt` / `sitemap.xml` | SEO |

## Deployment
GitHub Pages, `main` branch, root directory. Every push to `main` auto-deploys (~1 min).
